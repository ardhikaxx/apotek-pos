1. HALAMAN DASHBOARD
Halaman ini memberikan ringkasan statistik operasional apotek.

Kode Backend:
class DashboardController extends Controller
{
    public function index()
    {
        $totalProducts   = Product::count();
        $totalUsers      = User::count();
        $todayTotal      = Transaction::whereDate('transaction_date', today())->sum('total');
        $monthTotal      = Transaction::whereMonth('transaction_date', now()->month)
                            ->whereYear('transaction_date', now()->year)->sum('total');
        $lowStock        = Product::where('stock', 0)->count();
        $recentTx        = Transaction::with('user')->latest()->take(5)->get();

        return view('admin.dashboard.index', compact(
            'totalProducts', 'totalUsers', 'todayTotal', 'monthTotal', 'lowStock', 'recentTx'
        ));
    }
}

Penjelasan:
Fungsi ini bertujuan untuk menghitung total produk, total user, serta mengidentifikasi stok obat yang sudah habis. Selain itu, sistem juga menghitung total pendapatan secara real-time untuk hari ini dan akumulasi bulan berjalan dari data transaksi, serta mengambil lima riwayat transaksi terbaru untuk ditampilkan sebagai ringkasan aktivitas di halaman utama dashboard.

2. MANAJEMEN KATEGORI
Fitur untuk mengelola kategori obat (tambah, edit, hapus, lihat).

Kode Backend:
class CategoryController extends Controller
{
    public function index()
    {
        $categories = Category::withCount('products')->latest()->paginate(10);
        return view('admin.categories.index', compact('categories'));
    }

    public function store(Request $request)
    {
        $request->validate(['name' => 'required|string|max:100|unique:categories']);
        Category::create(['name' => $request->name]);
        return redirect()->route('admin.categories.index')->with('success', 'Kategori berhasil ditambahkan.');
    }

    public function destroy(Category $category)
    {
        if ($category->products()->exists()) {
            return back()->with('error', 'Kategori tidak bisa dihapus karena masih memiliki produk.');
        }
        $category->delete();
        return redirect()->route('admin.categories.index')->with('success', 'Kategori berhasil dihapus.');
    }
}

Penjelasan:
Metode index digunakan untuk menampilkan seluruh daftar kategori obat yang tersedia beserta perhitungan jumlah produk yang terasosiasi di setiap kategori. Pada fungsi store, sistem melakukan validasi ketat untuk memastikan nama kategori yang dimasukkan bersifat unik guna menghindari duplikasi data. Sementara itu, fungsi destroy dilengkapi dengan pemeriksaan integritas data yang mencegah penghapusan kategori jika masih terdapat produk aktif di dalamnya.

3. MANAJEMEN PELANGGAN
Mengelola data pelanggan yang terdaftar di sistem.

Kode Backend:
class CustomerController extends Controller
{
    public function index()
    {
        $customers = User::whereHas('role', function($q) {
            $q->where('name', 'pelanggan');
        })->latest()->get();

Penjelasan:
Fitur ini bekerja dengan cara memfilter data pengguna dari basis data yang secara khusus memiliki peran sebagai pelanggan. Dalam proses penambahan data pelanggan baru, sistem secara otomatis melakukan enkripsi atau hashing pada kata sandi yang dimasukkan untuk menjamin standar keamanan data pengguna.

4. MANAJEMEN PRODUK (OBAT)
Fitur utama untuk mengelola stok obat, harga, dan masa kadaluarsa.

Kode Backend:
class ProductController extends Controller
{
    public function index()
    {
        $products = Product::with('category')->latest()->paginate(10);
        return view('admin.products.index', compact('products'));
    }

    public function expired()
    {
        $products = Product::with('category')
            ->whereNotNull('expiry_date')
            ->where('expiry_date', '<', today())
            ->get();
        return view('admin.products.expired', compact('products'));
    }

    public function store(Request $request)
    {
        $request->validate([...]);
        Product::create($request->all() + ['is_active' => true]);
        return redirect()->route('admin.products.index')->with('success', 'Produk berhasil ditambahkan.');
    }

    public function addStock(Request $request, Product $product)
    {
        $request->validate(['qty' => 'required|integer|min:1']);
        $product->increment('stock', $request->qty);
        return back()->with('success', 'Stok berhasil ditambahkan.');
    }
}

Penjelasan:
Fungsi expired secara khusus menyaring dan menampilkan daftar obat yang masa berlakunya telah melewati tanggal hari ini agar dapat segera ditindaklanjuti. Admin juga memiliki akses ke fungsi addStock untuk menambah jumlah stok secara manual tanpa harus melalui prosedur pembelian formal, di mana setiap produk dikelompokkan berdasarkan kategori menggunakan relasi basis data yang tepat.

5. MANAJEMEN PEMBELIAN (STOK MASUK)
Mencatat pembelian obat dari supplier untuk menambah stok secara otomatis.

Kode Backend:
class PurchaseController extends Controller
{
    public function store(Request $request)
    {
        $request->validate([...]);
        DB::transaction(function () use ($request) {
            $total = 0;
            foreach ($request->items as $item) {
                $total += $item['quantity'] * $item['purchase_price'];
            }

            $purchase = Purchase::create([
                'supplier_id'   => $request->supplier_id,
                'user_id'       => auth()->id(),
                'purchase_date' => $request->purchase_date,
                'total'         => $total,
            ]);

            foreach ($request->items as $item) {
                PurchaseItem::create([...]);

                $product = Product::find($item['product_id']);
                $product->increment('stock', $item['quantity']);
                $product->update(['purchase_price' => $item['purchase_price']]);
            }
        });
        return redirect()->route('admin.purchases.index')->with('success', 'Pembelian berhasil dicatat.');
    }
}

Penjelasan:
Sistem memanfaatkan mekanisme transaksi basis data untuk menjamin konsistensi data, di mana seluruh proses akan dibatalkan jika terjadi kegagalan pada salah satu tahap input. Setelah data pembelian berhasil tersimpan, sistem akan secara otomatis meningkatkan jumlah stok produk yang bersangkutan dan memperbarui harga beli terakhir sebagai referensi perhitungan modal di masa mendatang.

6. LAPORAN PENJUALAN
Menampilkan dan mengekspor laporan transaksi penjualan.

Kode Backend:
class ReportController extends Controller
{
    public function index(Request $request)
    {
        $query = Transaction::with('user');
        if ($request->filled('start_date')) {
            $query->whereDate('transaction_date', '>=', $request->start_date);
        }
        if ($request->filled('end_date')) {
            $query->whereDate('transaction_date', '<=', $request->end_date);
        }
        $transactions = $query->latest()->paginate(15);
        $total = $query->sum('total');
        return view('admin.reports.index', compact('transactions', 'total'));
    }

    public function exportPdf(Request $request)
    {
        $transactions = $query->get();
        $pdf = Pdf::loadView('admin.reports.pdf', compact('transactions', 'total'))
                  ->setPaper('a4', 'landscape');
        return $pdf->stream('laporan-penjualan.pdf');
    }
}

Penjelasan:
Laporan penjualan dapat disaring secara fleksibel berdasarkan rentang tanggal mulai dan tanggal selesai sesuai kebutuhan pengguna. Sistem akan mengalkulasi total omzet yang dihasilkan selama periode terpilih tersebut dan menyediakan opsi untuk mengekspor seluruh rincian transaksi ke dalam format dokumen PDF menggunakan library DomPDF agar mudah dicetak atau dibagikan.

8. TRANSAKSI / POS (POINT OF SALE)
Modul kasir untuk melayani penjualan obat.

Kode Backend:
class TransactionController extends Controller
{
    public function store(Request $request)
    {
        DB::transaction(function () use ($request) {
            foreach ($request->items as $item) {
                $product = Product::lockForUpdate()->findOrFail($item['id']);
                if ($product->stock < $item['qty']) {
                    throw new \Exception("Stok {$product->name} tidak mencukupi.");
                }
                $product->decrement('stock', $item['qty']);
            }
            // Create transaction & items
        });
        return response()->json(['success' => true]);
    }

    public function printPdf(Transaction $transaction)
    {
        $pdf = Pdf::loadView('admin.transactions.pdf', compact('transaction'))
                  ->setPaper([0, 0, 226.77, 600], 'portrait');
        return $pdf->stream('struk.pdf');
    }
}

Penjelasan:
Pada modul kasir, sistem menerapkan penguncian data saat pengecekan stok untuk mencegah terjadinya bentrokan data atau penjualan melebihi stok yang tersedia. Setiap transaksi yang berhasil diselesaikan akan memicu pengurangan stok produk secara otomatis, dan pelanggan dapat menerima bukti pembayaran berupa struk belanja yang dicetak dalam format PDF dengan ukuran kertas thermal standar.

9. MANAJEMEN USER (ADMIN & APOTEKER)
Mengelola hak akses untuk staff apotek.

Kode Backend:
class UserController extends Controller
{
    public function index()
    {
        $users = User::whereHas('role', function($q) {
            $q->whereIn('name', ['admin', 'apoteker']);
        })->with('role')->latest()->paginate(10);
        return view('admin.users.index', compact('users'));
    }

    public function destroy(User $user)
    {
        if ($user->id === auth()->id()) return back()->with('error', 'Tidak bisa hapus diri sendiri.');
        if ($user->transactions()->exists()) return back()->with('error', 'User punya riwayat transaksi.');
        $user->delete();
        return redirect()->route('admin.users.index')->with('success', 'User berhasil dihapus.');
    }
}

Penjelasan:
Pengelolaan pengguna dibatasi hanya untuk akun dengan peran Admin dan Apoteker demi menjaga privasi dan keamanan sistem. Sebagai langkah perlindungan, admin tidak diizinkan untuk menghapus akun mereka sendiri saat sedang login, serta pengguna yang telah memiliki riwayat transaksi tidak dapat dihapus permanen untuk menjaga integritas laporan, melainkan hanya dapat dinonaktifkan statusnya.

2. POS (POINT OF SALE)
Fitur utama apoteker untuk melayani pembeli.

Kode Backend:
class PosController extends Controller
{
    public function index()
    {
        $customers = User::whereHas('role', fn($q) => $q->where('name', 'pelanggan'))->get();
        return view('apoteker.pos.index', compact('customers'));
    }

    public function store(Request $request)
    {
        $request->validate([
            'customer_id' => 'nullable|exists:users,id',
            'items'       => 'required|array|min:1',
            'items.*.id'  => 'required|exists:products,id',
            'items.*.qty' => 'required|integer|min:1',
            'paid_amount' => 'required|numeric|min:0',
        ]);

        DB::transaction(function () use ($request) {
            $total = 0;
            $itemsData = [];

            foreach ($request->items as $item) {
                $product = Product::lockForUpdate()->findOrFail($item['id']);

                if (!$product->is_active) {
                    throw new \Exception("Produk {$product->name} tidak aktif.");
                }
                if ($product->stock < $item['qty']) {
                    throw new \Exception("Stok {$product->name} tidak mencukupi.");
                }

                $subtotal = $product->selling_price * $item['qty'];
                $total += $subtotal;

                $itemsData[] = [
                    'product_id' => $product->id,
                    'qty'        => $item['qty'],
                    'unit_price' => $product->selling_price,
                    'subtotal'   => $subtotal,
                ];

                $product->decrement('stock', $item['qty']);
            }

            if ($request->paid_amount < $total) {
                throw new \Exception("Nominal bayar kurang.");
            }

            $invoice = 'INV-' . now()->format('Ymd') . '-' . str_pad(
                Transaction::whereDate('created_at', '=', today())->count() + 1, 4, '0', STR_PAD_LEFT
            );

            $transaction = Transaction::create([
                'user_id'          => auth()->id(),
                'customer_id'      => $request->customer_id,
                'invoice_number'   => $invoice,
                'total'            => $total,
                'paid_amount'      => $request->paid_amount,
                'change_amount'    => $request->paid_amount - $total,
                'transaction_date' => now(),
            ]);

            foreach ($itemsData as $item) {
                $transaction->items()->create($item);
            }

            session(['last_transaction_id' => $transaction->id]);
        });

        return response()->json(['success' => true, 'transaction_id' => session('last_transaction_id')]);
    }

    public function searchProduct(Request $request)
    {
        $products = Product::where('is_active', '=', true)
            ->where('stock', '>', 0)
            ->where('name', 'like', '%' . $request->q . '%')
            ->with('category')
            ->get(['id','name','selling_price','stock','unit','category_id']);

        return response()->json($products);
    }

    public function show(Transaction $transaction)
    {
        $transaction->load('items.product', 'user', 'customer');
        return view('apoteker.pos.show', compact('transaction'));
    }

    public function printPdf(Transaction $transaction)
    {
        $transaction->load('items.product', 'user', 'customer');
        $pdf = Pdf::loadView('apoteker.pos.pdf', compact('transaction'))->setPaper([0, 0, 226.77, 600], 'portrait');
        return $pdf->stream('struk-' . $transaction->invoice_number . '.pdf');
    }
}

Penjelasan:
Modul kasir atau Point of Sale (POS) ini dirancang untuk menangani seluruh alur transaksi penjualan secara efisien dan aman. Sistem menyediakan fitur pencarian produk secara real-time yang memfilter produk aktif dengan stok tersedia, serta memungkinkan pemilihan pelanggan terdaftar untuk pendataan riwayat belanja. Dalam proses penyimpanan (store), sistem menerapkan validasi input yang ketat dan menggunakan mekanisme Database Transaction bersama dengan Row-Level Locking (lockForUpdate) untuk menjamin konsistensi stok meskipun terjadi akses bersamaan. Selain itu, sistem secara otomatis menghasilkan nomor invoice unik berbasis tanggal, menghitung kembalian, memperbarui stok fisik, dan menyediakan fungsionalitas untuk mencetak struk belanja dalam format PDF yang dioptimalkan untuk printer thermal. Pelacakan transaksi juga diperkuat dengan penyimpanan data kasir yang bertugas serta rincian item produk yang terjual guna keperluan pelaporan yang akurat.
